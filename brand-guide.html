Yu's Daily Scope

取景器四角负责「看」，框里是一颗带光环的星球：每天都有一个值得看见的世界。一条闭合的倾斜轨道环分前后两层穿过球面，暖黄留给卫星与星点。中文副名沿用「小宇晨报 · 每日机会简报」。

96 × 96 GRID · 3 COLOR SYSTEM

02

构造

96 单位网格 / 12 单位安全边距
  • 网格与安全区96 × 96 单位栅格，图形外沿距边界 12u；虚线方框为取景范围 72 × 72u。
  • 取景四角四段 L 形 bracket，臂长 20u，线宽 2.2u，直角端点。这是「摄影」的一半：先框住视野，再看里面有什么。
  • 星球本体圆心 (48,48)，半径 16u。蓝绿亮面 + 深墨蓝暗面，暗面由一个右偏 19u 的等圆裁切而成，形成一道晨昏线，光从左上照来。
  • 闭合轨道环一条 rx31 / ry10.5 的椭圆，绕中心旋转 −14°。上半弧 32% 透明度留在星球之后，下半弧实色压过球面，两段在左右极值点 (17,48) / (79,48) 相切闭合——环是完整的一圈，没有首尾相交的尖角，也像镜头前的对焦环。
  • 卫星与星点环右端暖黄卫星 r3.2，恰好盖住两段弧的接缝；右上内侧一颗十字星芒。暖黄仍是「今天」，只是从静止的焦点变成绕行的卫星。
  • 视觉逻辑三层递进：取景框（看什么）→ 星球（一整个世界）→ 卫星（今天）。环修正为闭合轨道后，框、球、环、卫星各归其位，不再被读成一张脸。
03

变体

纯图标 / 竖版 / 单色 / 反白
✓最小使用尺寸 16px；16–24px 时四角、球面明暗与暖黄卫星仍可辨识，星芒会弱化为一点。
✓深色背景一律使用 Reversed 版，星球暗面会融进底色形成一弯亮面，不要直接把浅底版反相。
×不拉伸、不旋转、不加阴影或外发光，不改三色的相对亮度关系。
×不把暖黄卫星改成其他颜色，不把轨道环拉平、改成正圆或拆成两条相交弧，也不在图标外加底板。

05

字标规范

克制来自字重对比，不来自花体

主字标

Yu's 用 400 字重，Daily Scope 用 600 字重，字号 24.5 / 96 单位，字距 .01em。撇号使用 ASCII 直撇号 '，不是弯引号。

推荐 SF Pro Display / Inter / Helvetica Neue；中文副名用 PingFang SC，不与英文主标混排在同一行。

副标与安全边距

MORNING BRIEF · 07:30，字号 8.8，字距 .24em，全大写。这条信息是发布节奏，不随内容变化。

横版锁定四周留白 ≥ 16px；图标与文字之间的 1px 分隔线不透明度 16%，只起对齐作用，不是装饰线。
